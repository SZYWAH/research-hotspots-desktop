# 科研 Agent 分阶段实施路线

状态：最终产品详细实施路线

更新时间：2026-07-27

权威路线入口：[科研 Agent 路线图](./ROADMAP.md)

产品目标：[科研 Agent 最终产品目标](./RESEARCH_AGENT_PRODUCT_GOAL.md)

本文是详细长期实施蓝图，不记录当前开发状态或进度。当前阶段、实现事实和实际开发过程以 `PROJECT.md`、`ROADMAP.md`、`STATUS.md`、`ARCHITECTURE.md`、`DECISIONS.md` 和 `DEVELOPMENT.md` 六份入口文档为准。

## 1. 路线目标

本文将最终科研 Agent 产品拆解为可以独立开发、验证和回退的阶段。路线遵循“先锁定真实性和接口，再逐步交付完整体验”，避免一次性重写现有程序。

实施完成后的主路径是：

```text
启动程序
  → 沉浸式 Agent 星空首页
  → 本地混合检索 / 受控联网检索
  → 可点击论文与热点证据
  → 对话驱动星空聚焦
  → 发起导入、清洗、建模和报告任务
  → 星系诞生观测站展示真实建模过程
  → 正式理论星图与可审计研究成果
```

## 2. 当前基础

以下能力已经存在，应复用而不是重写：

- SQLite 本地论文库和项目隔离。
- V20 快照、热点、论文归属、代表论文和血缘。
- 本地 E5 Embedding、缓存和理论星图三维布局。
- 展示星图、理论星图、热点系统和论文相机旅程。
- 受监督 Agent 的计划、工具、审批、预算、租约、事件和 Artifact。
- 报告生成、引用审计、人工复核和正式导出边界。
- OpenAI 兼容协议、Anthropic 协议和用户模型配置。
- OpenAlex、arXiv 和 CNKI 的独立检索页面能力。
- 大文件导入、恢复、清洗、建模和原子快照提交。
- Windows Tauri、迁移、备份和凭据管理。

当前主要差距：

- 默认入口仍是 Dashboard。
- Agent 页面是运行管理工作台，不是极简对话首页。
- 全局功能边栏默认可见。
- 本地 Agent 搜索仍以 `LIKE '%term%'` 为主，没有最终 FTS5/BM25 索引。
- E5 尚未形成面向对话的混合检索层。
- 在线检索未注册为受治理 Agent 工具。
- 星空背景尚未成为 Agent 对话的空间界面。
- 建模事件只有阶段/计数，没有临时热点和论文位置增量。
- 聚类页不能真实展示星系生长。

## 3. 实施原则

### 3.1 不做大爆炸重写

每个阶段必须：

- 保留上一阶段可运行版本。
- 使用独立分支或清晰提交边界。
- 为新增数据结构提供迁移和回退。
- 不以删除现有专业页面换取首页简洁。
- 在浏览器视觉验收通过后再做 Tauri 原生验收。

### 3.2 数据真实性优先

- Agent 视觉不得伪造论文或热点。
- 建模预览不得成为活动快照。
- 联网结果不得未经批准写入本地库。
- 回答引用必须绑定真实证据。
- 模型不能自行降低工具风险。

### 3.3 视觉和能力并行

早期建立隔离的 Agent 星空视觉原型，尽快验证产品辨识度；同时优先完成检索和会话数据契约，避免视觉原型反向绑死数据架构。

### 3.4 性能从第一阶段开始记录

所有长期运行的星空、检索、流式回答和建模预览都必须从首次实现起记录：

- 平均/P95帧耗时。
- CPU 和 GPU 占用。
- 内存和显存。
- 首帧时间。
- 检索延迟。
- 索引构建时间。
- 事件吞吐和丢弃数量。

## 5. 阶段 0：目标、基线与当前星图收口

### 5.1 目标

建立不会继续漂移的产品定义和代码基线。

### 5.2 工作

1. 将产品目标和本路线纳入 `docs/`。
2. 在历史 V20、Agent 和延后路线文档中标记新的权威入口。
3. 收口当前理论星图直线飞近、普通论文星可见度和语义原位成轨改动。
4. 修复终局就绪审计中硬编码旧版本的问题。
5. 保存当前展示/理论星图视觉快照、性能摘要和审计结果。
6. 明确当前生产布局和 UMAP 实验边界；未人工选择前继续使用现有生产布局。
7. 确定阶段 1 的隔离视觉评审入口，不直接替换主程序首页。

### 5.3 交付物

- 两份权威文档。
- 干净、可回退的星图基线提交。
- 当前星图浏览器和 Tauri 验收记录。
- Agent 背景视觉原型输入数据契约草案。

### 5.4 退出门槛

- 当前自动审计和构建全部通过。
- 展示星图无非预期改变。
- 理论星图进入/退出和代表论文交接通过。
- 工作树中不存在来源不明的混合改动。
- 旧文档不再把 V20 工作站描述成最终产品目标。

## 6. 阶段 1：可复用星空表现层与 Agent 背景原型

### 6.1 目标

在不改动默认启动页的前提下，制作可独立评审的沉浸式 Agent 星空背景，验证“第一眼惊艳”是否成立。

### 6.2 数据契约

定义只读的 `AgentGalaxyBackgroundPayload`（名称可调整），至少包含：

- 数据库身份。
- 项目 ID。
- 背景快照 ID。
- 布局/坐标空间版本。
- 热点 ID、方向、颜色、置信度和趋势。
- 确定性抽样论文 ID、热点归属和相对坐标。
- 视觉配置版本。
- 活动快照是否更新。

背景载荷与分析星图载荷分开：

- 可以从同一理论快照派生。
- 不复制完整 25K/100K 论文集合。
- 不允许背景视觉参数反向改变正式星图。

### 6.3 渲染结构

建立独立背景组件，复用必要的数学和视觉工具，但不直接把完整分析星图页面挂在首页。

至少支持：

- 多层确定性星尘。
- 热点代理。
- 论文代理。
- 学科温度族。
- 深度视差。
- 缓慢相机漂移。
- 星流/能量丝。
- 局部 Bloom 和景深。
- 空闲、输入、回答、阅读四种运动状态。
- `prefers-reduced-motion`。
- 页面隐藏和失焦暂停。
- 集显自动降级。

### 6.4 视觉探索

至少制作三套可切换的隔离候选：

1. 深空航行：明显前后景和缓慢穿行。
2. 星系呼吸：热点能量和星流主导。
3. 科研信号：低频深空背景加偶发新信号和数据脉冲。

三套候选使用相同数据和相机预设，提交截图、短录屏和性能指标，由人工选定后再进入正式首页。

执行状态（2026-07-27）：三套候选已经交付，但人工视觉验收失败。它们只作为基础设施验证和失败基线保留。阶段 1 已重新打开，后续改为先建立可替换的参数化 FlowModel、锐利语义星分层和动态论文焦点，再通过动态材料选择主视觉；最终流动形态暂不固定。

### 6.5 性能测试

最低覆盖：

- Intel Iris Xe / 1080p。
- RTX 4060 / 1080p。
- 普通窗口与全屏。
- 30 秒空闲。
- 30 秒模拟流式回答。
- 失焦、恢复和减少动态。

### 6.6 退出门槛

- 人工选定一个主视觉方向。
- 集显空闲背景达到 30 FPS 目标或自动稳定降级。
- 输入和模拟流式文本无明显卡顿。
- 背景快照和活动快照身份可审计。
- 视觉层不存在无法回溯到数据或明确展示规则的实体。

## 7. 阶段 2：应用外壳、默认入口与页面合并

### 7.1 目标

将程序从“固定侧栏的多页面工作站”重构为“Agent 首页＋按需专业工具空间”。

### 7.2 默认路由

- 正常启动默认 `activeView="agent-home"`。
- 视觉评审、深链接和恢复操作可以显式进入其他页面。
- 无数据库、无快照、无 API 时仍显示 Agent 首页空状态。
- 首次启动不得自动运行导入、清洗、建模或联网。

### 7.3 导航抽屉

- 全局边栏每次启动默认关闭。
- 右上角显示小型半透明入口。
- 点击后以覆盖层滑入。
- `Escape`、点击遮罩和关闭按钮退出。
- 键盘焦点被限制在打开的抽屉中并在关闭后恢复。
- 小窗口下成为全高抽屉。

### 7.4 文献与建模

建立统一入口，但保留内部模块边界：

```text
LiteratureModelingWorkspace
  ├─ Search
  ├─ Library
  ├─ Reader
  ├─ Imports
  ├─ Cleaning
  ├─ Embedding
  ├─ Modeling Observatory
  └─ Recovery
```

旧文献和流水线入口可以在迁移期保留兼容深链接，最终在边栏中只显示“文献与建模”。

### 7.5 Agent 运行详情

现有 `AgentWorkspace` 保留计划、审批、步骤、事件、Artifact、预算和治理功能，改为：

- “Agent 运行详情”专业页面。
- Agent 首页中的治理抽屉数据来源。
- 对话中高风险动作的详细审查入口。

### 7.6 回归测试

- 所有旧页面仍可到达。
- 页面切换不触发自动建模。
- 星图 keep-alive 和画布尺寸恢复。
- 论文阅读和报告页面状态保留。
- 导航抽屉无焦点泄漏。
- 经典布局或等效回退路径可用。

### 7.7 退出门槛

- 程序启动直接进入 Agent 首页。
- 边栏默认关闭。
- 文献与建模入口能够访问原有全部关键功能。
- 无数据/无模型状态不形成死路。
- 原有专业页面自动审计与原生烟测通过。

## 8. 阶段 3：FTS5＋E5 本地混合检索

### 8.1 目标

把本地论文检索从兼容性 `LIKE` 扫描升级为可服务 25K/100K Agent 多轮对话的证据检索层。

### 8.2 Schema 与迁移

新增版本化检索结构，包含：

- FTS5 论文索引。
- 论文 ID 与项目 ID 的外部内容映射。
- 标题、摘要、作者、关键词等独立或加权字段。
- 索引版本和构建状态。
- 数据库修订、内容哈希和模型版本。
- 可恢复的批量回填进度。

迁移要求：

- 既有数据库升级前继续遵守备份规则。
- 索引可以删除后重建，不成为论文事实权威。
- 回填中断可续跑。
- 新增、更新和删除论文后增量同步。

### 8.3 中文检索决策门

在实现前运行兼容性实验：

1. 检查打包 SQLite 的 FTS5 与 trigram 能力。
2. 使用中英文混合查询评估召回、索引大小和延迟。
3. 若 trigram 不可用或质量不足，使用应用层稳定 n-gram/分词字段。
4. 将选定 tokenizer/索引方式写入索引版本。

不得仅凭开发机 SQLite 行为假设安装包环境一致。

### 8.4 语义召回

复用当前 E5 Embedding 缓存：

- 查询文本生成同版本 E5 向量。
- 按项目、年份、来源、学科或热点预过滤。
- 计算语义相似度。
- 输出论文 ID、分数和证据片段。

100K 语义召回需要决策门：

- 先基准测试候选集内精确余弦检索。
- 若 P95 不达标，再选择持久化 HNSW 或经过打包验证的 SQLite 向量扩展。
- 索引必须绑定模型 revision 和数据库修订。

### 8.5 混合重排

统一检索结果至少考虑：

- BM25 分数。
- E5 余弦相似度。
- 查询字段命中。
- 年份和来源过滤。
- 热点相关度。
- 重复标题/DOI 合并。
- 来源多样性。

权重配置必须版本化，并提供离线查询集评测。

### 8.6 接口

新增稳定的只读检索接口，返回：

- 查询与过滤条件。
- 索引和模型版本。
- 论文 ID。
- 词法/语义/综合分数。
- 证据片段。
- 热点归属。
- 是否截断。
- 查询耗时和候选数量。

Agent 不能读取未限制的整库全文。

### 8.7 验收

测试集至少包含：

- 中文关键词。
- 英文关键词。
- 中英文混合。
- 精确标题。
- 方法同义表达。
- 热点语义查询。
- 年份/来源组合过滤。
- 无结果与歧义查询。

性能基准分别使用：

- 25K 真实/当前库。
- 100K 合成性能库。

具体延迟阈值在阶段开始时根据最低设备基线锁定，并进入自动审计；不得只记录平均值，必须记录 P95。

### 8.8 退出门槛

- Agent 默认不再依赖 `%term%` 扫描。
- 索引构建、增量更新、删除和中断恢复通过。
- 中英文查询质量人工验收通过。
- 25K/100K P95 达到锁定阈值。
- 每条结果可以回到真实论文和片段。

## 9. 阶段 4：Chat-first Agent 核心

### 9.1 目标

建立可持久化、可流式、可引用、可停止，并与现有受监督运行系统连接的主对话体验。

### 9.2 数据模型

建议新增或扩展：

- `agent_conversations`
- `agent_messages`
- `agent_message_citations`
- `agent_message_tool_summaries`
- `agent_visual_focus_intents`

记录：

- 项目和数据库身份。
- 会话标题、状态和时间。
- 消息角色和可见内容。
- 流式提交边界。
- 引用和证据片段。
- 对应 Agent run/Artifact。
- 模型配置哈希。

不记录思维链。

### 9.3 模型 Provider 层

统一接口覆盖：

- OpenAI Chat Completions。
- OpenAI Responses。
- Anthropic Messages。
- 自定义 Base URL 和模型名称。
- 流式增量。
- 取消。
- 超时。
- 结构化输出。
- Token/费用统计。

特殊供应商通过明确适配器扩展，不提供任意请求模板。

凭据继续保存在 Windows Credential Manager。前端只能获得“已配置/未配置”和脱敏 Provider 元数据。

### 9.4 对话编排

对话请求分为：

1. 普通证据问答。
2. 需要本地检索。
3. 需要在线补充。
4. 需要澄清。
5. 需要创建受监督运行。
6. 需要打开专业页面或空间聚焦。

只读问答可以轻量执行；涉及多步骤、写入或高风险动作时，创建现有 Agent run，并在对话中显示简洁状态卡。

### 9.5 极简 UI

- 初始小型半透明输入框。
- 第一条消息后渐进展开。
- 支持流式文本和停止按钮。
- 引用以低干扰形式嵌入。
- 长回答进入低干扰阅读状态。
- 治理详情从抽屉或专业页面打开。

### 9.6 无模型状态

未配置模型 API 时：

- 仍可打开 Agent 首页。
- 可以进入本地检索界面或查看配置引导。
- 不伪装生成式回答。
- 不自动发送任何网络请求。

### 9.7 验收

- 新建、恢复、重命名、归档和删除会话。
- 流式中断和停止。
- WebView 重启恢复已提交消息。
- 本地检索引用正确。
- 快照变化后旧证据不会与新快照混用。
- 高风险动作进入审批，不在聊天层直接执行。
- API Key 不进入日志和 Artifact。

### 9.8 退出门槛

- 用户可以从首页完成一次带本地论文引用的完整问答。
- 可以点击引用打开论文。
- 可以从对话创建受监督报告任务。
- 断网、超时、取消和应用重启均有明确恢复行为。

## 10. 阶段 5：对话驱动的星空聚焦

### 10.1 目标

把论文和热点引用转化为可追踪的空间交互，使背景成为科研上下文而不是装饰。

### 10.2 结构化焦点意图

模型不直接返回相机参数。后端根据已验证实体生成：

- `intentId`
- `entityType`
- `entityIds`
- `primaryEntityId`
- `databaseIdentity`
- `snapshotId`
- `focusMode`
- `confidence`

前端只接受能够在当前数据库/快照中解析的意图。

### 10.3 行为

- 单热点：自动飞向热点邻域。
- 单论文：先进入所属热点，再飞向论文。
- 多实体：同屏点亮并以引用编号连接。
- 顺带提及：只呼吸。
- 点击引用：显式聚焦。
- `Escape`：从当前进度连续返回。
- 新焦点：当前过渡结束前排队或按明确规则替换。

### 10.4 新信号

实体不在固定背景快照时：

- 显示新信号，而不是放入伪造位置。
- 使用活动快照的已验证语义方向作为临时展示依据。
- 标明来源快照差异。
- 提供“本次显示”和“更新背景”选项。

### 10.5 验收

- 小、中、大热点各覆盖至少两个。
- 单论文、单热点、多实体和新信号均覆盖。
- 相机距离和轨迹连续。
- 对话框与焦点星体不遮挡。
- 回答开始后背景自动降噪。
- 不存在对象替换、重排或亮度跳变。

### 10.6 退出门槛

- 用户能从回答引用追踪到星空实体和论文详情。
- 新旧快照不会形成虚假空间关系。
- 集显下聚焦和流式回答可以同时运行。

## 11. 阶段 6：受控在线学术与网页检索

### 11.1 目标

当本地证据不足时，Agent 能透明地补充在线证据，同时保持来源、许可和入库边界。

### 11.2 后端连接器

将现有前端学术检索迁移或重写为后端受治理工具：

- OpenAlex
- arXiv
- Crossref
- PubMed

每个连接器定义：

- 工具名和版本。
- 查询 schema。
- 超时、频率和结果上限。
- 来源和许可元数据。
- 结果标准化。
- 错误和重试边界。

### 11.3 受控通用网页搜索

第一阶段只允许：

- 调用明确的搜索服务。
- 获取公开搜索结果。
- 读取允许访问的公开页面。
- 提取有限文本和来源信息。

禁止：

- 自动登录。
- 任意浏览器控制。
- Cookie 导出。
- 绕过付费墙、验证码或机构权限。
- 按页面文本指令执行外部动作。

### 11.4 临时证据

在线证据单独存储会话级 provenance：

- 来源 URL。
- 标题。
- 查询。
- 获取时间。
- Provider。
- 许可/访问说明。
- 内容摘要和哈希。

用户批准入库前，不进入正式论文表和 V20 快照。

### 11.5 机构连接器协议

预留独立能力层：

- 正式 API。
- OAI-PMH。
- Z39.50。
- 供应商授权接口。
- 用户授权数据库连接。

凭据按项目和服务商存入 Windows Credential Manager，不进入 Agent 上下文。

### 11.6 验收

- 本地证据足够时不无谓联网。
- 联网状态在界面中可见。
- 在线与本地引用可区分。
- 重试不会重复入库或重复扣用受限配额。
- 未确认时在线结果不写本地库。
- 各连接器断网、限流和返回异常均有明确错误。

### 11.7 退出门槛

- Agent 可以完成一次“本地不足→在线补充→带来源回答”的任务。
- 用户可以选择部分结果入库。
- 所有在线证据具有 provenance。
- 没有任意浏览器或访问控制绕过能力。

## 11A. 阶段 6A：全文文档基座与沉浸阅读工作台

### 11A.1 目标

让论文实体关联真实、可版本化、可按页引用的全文，并交付以 PDF 为首期格式的沉浸阅读工作台。该阶段依赖阶段 3 的本地索引和阶段 4 的 Agent Provider 层，但不依赖校园图书馆连接器完成后才开始。

### 11A.2 来源与文档身份

首批来源：

- 本地上传、拖放和文件选择。
- 用户在浏览器、图书馆或出版社网站合法下载后导入。
- 开放获取仓储和正式 API。
- 后续受治理的机构连接器。

建议的概念实体（具体表名在实现前评审）：

- `Document`：逻辑文档身份。
- `DocumentVersion`：具体文件、格式、内容哈希和版本。
- `DocumentSource`：URL、DOI、Provider、访问方式、许可和获取时间。
- `DocumentPage / Segment`：页码、章节、文本、页面坐标和提取置信度。
- `DocumentAnnotation`：用户高亮、批注和阅读位置。

原文件只读保存；解析和索引可以重建。论文记录不得因导入新版本而丢失旧文件或来源。

### 11A.3 解析与索引

1. 校验 MIME、文件头、大小和内容哈希。
2. 优先提取 PDF 原生文本、阅读顺序、页码、目录、章节、引用和图表标题。
3. 扫描件按需进入 OCR，并保存页面图像、坐标和置信度。
4. 建立文档级 FTS/BM25 和 E5 索引。
5. 片段引用必须携带文档版本、页码、章节和文本/坐标范围。
6. 长文总结使用“章节检索→分层摘要→带锚点汇总”，不把整篇无限制送入模型。

### 11A.4 阅读体验

- 连续页与单页模式。
- 缩放、目录、页码跳转和全文搜索。
- 文本选择、高亮、批注和阅读位置恢复。
- 从论文星、热点、对话引用和报告引用深链接进入。
- 阅读态使用低干扰背景；正文滚动和选择不受星空渲染影响。
- 期刊卷期表现为元数据、目录和文章集合；整期扫描版作为独立文档版本保留。

### 11A.5 AI 阅读侧边栏

首批能力候选：

- 选段/当前页/章节翻译。
- 章节与全文分层总结。
- 方法、术语、公式、图表和统计结论解释。
- 围绕当前文档自由问答。
- 与本地论文库、热点、引用和其他已打开文献对照。

工具调用必须显式携带作用范围，结果引用页面锚点。默认只发送最小必要片段；向外部 Provider 发送整篇文本、页面图像、表格或敏感文档前必须二次确认。AI 结果与原文、用户批注分层保存。

### 11A.6 分步交付

1. 文档身份、版本、来源和许可模型。
2. 本地 PDF 导入、去重和原文件存储。
3. 无 AI 的稳定阅读器。
4. 文本提取、页码锚点、全文搜索与片段索引。
5. 选段翻译和解释。
6. 章节/全文分层总结与文档内问答。
7. OCR、图表/公式辅助和更多格式。

### 11A.7 退出门槛

- 上传或导入 PDF 后能够稳定阅读并恢复位置。
- 任意提取文本能够回到精确文件版本和页面。
- 原生文本与 OCR 来源明确区分。
- AI 回答包含可点击页码/章节证据。
- 外部模型发送范围可见、可取消、可审计。
- 删除派生索引后原文件和用户批注仍安全。

## 11B. 阶段 6B：校园图书馆与机构来源连接器

### 11B.1 目标

在不采集校园账号密码、不绕过访问控制的前提下，完成“馆藏发现→用户授权→单篇获取→来源记录→阅读台打开”的闭环。

### 11B.2 连接器能力模型

每个连接器声明实际能力：

- `search`
- `metadata`
- `resolve-link`
- `open-in-browser`
- `download-single-document`
- `quota-and-rate-limit`

不得以“校园图书馆”一个通用抓取器覆盖所有学校和供应商。学校门户通常只是入口，实际资源可能来自不同 OPAC、发现系统、链接解析器和数据库供应商，必须分别适配。

### 11B.3 分步接入

1. 调研目标学校门户、身份认证、馆藏目录、链接解析器和首批数据库。
2. 首先实现 OPAC/OpenURL/DOI 的发现与跳转。
3. 接入正式 OAI-PMH、Z39.50 或供应商 API。
4. 对无正式全文 API 的来源，仅允许用户在系统浏览器/外部浏览器自行登录和下载，再通过明确文件导入进入应用。
5. 只有条款允许时才增加正式授权的单篇下载回调或供应商连接器。
6. 所有结果统一写入 provenance；在线元数据和全文未经用户确认不进入正式论文库。

### 11B.4 安全与合规

- API Token 存入 Windows Credential Manager。
- 校园账号密码始终留在机构登录页面。
- 不导出 Cookie，不模拟验证码，不绕过付费墙、IP、VPN 或并发限制。
- 默认禁止无人值守批量下载和跨用户共享全文。
- 记录 Provider、机构、获取时间、许可说明、文件哈希和失败原因。
- 用户配置的 AI Provider 不自动获得机构全文。

### 11B.5 退出门槛

- 至少一个真实目标学校完成受控端到端验收。
- 未登录、登录过期、无全文权限、限流和供应商错误均明确可恢复。
- 单篇全文进入 11A 文档基座后来源完整、可去重、可阅读。
- 连接器关闭或删除凭据后不会破坏已合法导入的本地文档。
- 自动测试不使用真实校园密码、Cookie 或受版权保护的全文夹具。

## 12. 阶段 7：真实建模预览协议

### 12.1 目标

扩展当前建模进度，使前端能够显示真实的论文和热点增量，而不提前提交活动快照。

### 12.2 事件模型

现有 `semantic-modeling-progress` 继续承担概要状态。新增版本化预览事件，例如：

- `modeling-preview-start`
- `modeling-preview-paper-batch`
- `modeling-preview-proto-hotspot-batch`
- `modeling-preview-assignment-delta`
- `modeling-preview-layout-delta`
- `modeling-preview-lineage-delta`
- `modeling-preview-commit`
- `modeling-preview-failed`

具体命名在实现前确定，但事件必须包含：

- 运行/operation ID。
- 数据库和项目身份。
- 输入库修订。
- 序列号。
- 阶段。
- 批次范围。
- 是否临时。
- 算法和布局版本。

### 12.3 稳定身份

- 论文粒子槽位由论文 ID 稳定映射。
- 临时热点具有运行内稳定 ID。
- 合并、拆分和重命名通过 lineage delta 表达。
- 位置更新只发送同一实体的变化。
- 不通过排序重建整个数组。

### 12.4 数据量控制

数万/十万论文不能逐点逐帧传输：

- 事件按 100–250 ms 节流。
- 论文使用确定性可视抽样或量化增量。
- 热点和关键论文可以全量发送。
- 前端丢弃过期序列，不倒放陈旧增量。
- 队列压力过高时合并中间位置，只保留最新状态。

### 12.5 隔离与事务

- 预览数据存于运行态缓存或专用可恢复预览存储。
- 不写入活动 V20 表。
- 最终 `write_snapshot_transaction` 仍是唯一正式切换点。
- 取消、失败或租约失效后不能提交。
- WebView 重载可以从后端当前预览状态恢复。

### 12.6 测试

- 序列乱序、重复和丢失。
- 暂停和恢复。
- WebView 重载。
- 取消。
- 后端失败。
- 快照提交失败。
- 旧运行事件污染新运行。
- 25K/100K 事件吞吐。

### 12.7 退出门槛

- 前端能只依靠真实事件重建当前预览。
- 预览不污染活动快照。
- 论文和热点身份在事件中稳定。
- 事件吞吐不会显著拖慢 Embedding 和建模。

## 13. 阶段 8：星系诞生观测站

### 13.1 目标

把阶段 7 的真实事件表现为“混沌星尘逐渐凝聚并最终成为理论星图”的可交互过程。

### 13.2 单一粒子所有权

使用单一稳定论文粒子层：

- 初始位置由论文 ID 稳定生成。
- 同一粒子逐步获得亮度、语义方向和归属。
- 不在阶段切换时创建替代对象。
- 状态通过属性和 blend 连续变化。

热点同样使用稳定对象和 lineage 交接。

### 13.3 视觉状态机

#### 黑暗期

- 展示数据库读取、缓存检查和真实吞吐。
- 不显示尚未计算出的热点。

#### 星尘苏醒

- Embedding 完成批次逐颗/逐批获得微光。
- 缓存命中与新计算可以采用不同但克制的视觉状态。

#### 混沌流动

- 已有语义向量的论文形成连续流场。
- 未完成论文继续保持低能量尘埃。

#### 原恒星核心

- 只在后端产生真实临时聚类后出现。
- 核心亮度和大小反映临时论文数与稳定度。

#### 引力凝聚

- 论文沿 C1/C2 连续轨迹向真实临时热点移动。
- 归属变化从当前位置重新规划，不瞬移、不回到初始点。

#### 星系重组

- 合并：两个核心和论文云连续向新核心交接。
- 分裂：密度场先拉伸，再形成两个真实子核心。
- 消失：能量衰减并将论文所有权转给新归属。
- 重命名：只改标签，不改变实体身份。

#### 语义定形

- 三维布局增量到达后，整体连续收敛到理论位置。
- 不按最终排序重新排列粒子缓冲。

#### 原子提交

- 成功提交后去除临时状态。
- 预览相机和正式理论星图相机进行投影一致交接。
- 屏幕位置和云尺度不得明显跳变。

### 13.4 交互

- 鼠标旋转和缩放。
- 暂停观察，不暂停后端时需明确区分“暂停画面”和“暂停任务”。
- 悬停临时热点查看阶段、稳定度和论文数。
- 离开页面后任务继续。
- 返回后恢复当前后端状态。
- 完成后进入正式理论星图。

### 13.5 诊断

记录：

- 真实后端阶段与前端视觉阶段延迟。
- 接收、合并和丢弃的事件数量。
- 活跃论文/热点代理数量。
- 粒子身份替换数量（必须为零）。
- 最大位置步进和亮度步进。
- 合并/分裂次数。
- 预览和正式理论星图交接投影误差。
- 建模额外 CPU、内存和耗时。

### 13.6 验收

- 小库功能测试。
- 25K 真实库视觉与性能。
- 100K 压力库吞吐。
- 缓存大量命中和几乎无命中两种路径。
- 合并、分裂、取消、暂停、失败和成功。
- 长时间离开页面后返回。
- 最终理论星图与正式载荷一致。

### 13.7 退出门槛

- 所有可见实体来自真实事件。
- 论文粒子身份替换为零。
- 不出现排队、归位、瞬移或整体闪现。
- 完成后无缝成为正式理论星图。
- 预览带来的建模耗时和资源增量在锁定预算内。

## 16. 风险与应对

| 风险 | 影响 | 应对 |
|---|---|---|
| 首页背景占用过高 | 输入和流式回答卡顿 | 独立轻量载荷、集显预算、自动降级 |
| 星空视觉与数据混淆 | 用户误解展示坐标 | 固定快照身份、明确沉浸式表达标记 |
| FTS 中文效果不足 | 本地检索质量差 | trigram/应用层 n-gram 决策门与人工查询集 |
| 100K 语义召回过慢 | Agent 响应不可用 | 候选预过滤、持久化近邻索引决策门 |
| Provider 差异过大 | 流式和结构化输出不稳定 | 适配器注册表和能力探测，不做任意 HTTP 模板 |
| 在线搜索污染本地库 | 证据和许可失控 | 临时证据区、明确入库审批、provenance |
| 建模预览拖慢聚类 | 总耗时恶化 | 节流、抽样、量化、事件合并和性能预算 |
| 临时热点频繁重组 | 视觉混乱 | 密度场过渡、稳定身份、清晰临时状态 |
| 前端假进度 | 破坏可信度 | 只消费真实事件；回放必须明确标记 |
