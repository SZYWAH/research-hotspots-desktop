# 科研 Agent 决策记录

更新时间：2026-07-28

## D-001：重新打开 M1

状态：已接受

旧 `voyage / breath / signal` 原型的基础设施验证有效，但人工视觉验收失败。M1 必须重新打开，不能因构建或静态审计通过而标记完成。

## D-002：旧候选只保留历史

状态：已接受

旧候选保留在 Git 历史和验收材料中，不删除、不继续作为产品候选，也不作为新视觉的截图基准。

## D-003：背景使用展示坐标空间

状态：已接受

理论坐标继续提供身份、热点归属和语义关系，但 Agent 背景允许使用版本化流场重新表达位置。展示变换不得反向修改理论星图或声称自己是严格理论坐标。

## D-004：流动形态暂不固定

状态：已接受

先建立可替换 `FlowModel`。引力织场用于第一轮技术验证，潮汐/Curl 流保留为后续适配器；两者都不预设为产品候选，最终形态必须依据动态视频人工选择。

## D-005：清晰度优先于粒子数量

状态：已接受

语义星必须拥有全分辨率锐利亮核，不参与景深模糊、运动模糊和低分辨率放大。性能不足时先减少装饰粒子和后处理。

## D-006：颜色克制

状态：已接受

默认颜色以银白、冷灰和低饱和灰蓝为主。热点通过尺寸、密度和局部关系表达，只有当前焦点允许短暂增加能量或饱和度。

## D-007：3,840 是常驻预算，不是检索边界

状态：已接受

背景只常驻 3,840 个确定性抽样论文代理。库中其他论文通过只读解析和动态焦点层按需出现。

## D-008：区分快照内未抽样与新信号

状态：已接受

背景快照内未抽样论文直接在所属流带凝聚；只存在于活动数据库或更新快照的论文标记为“新信号”；不存在实体不伪造位置。

## D-009：呼吸不改变语义星核心透明度

状态：已接受

呼吸使用局部密度、空间潮汐和弱光晕变化。语义星中央亮核不得通过时间驱动透明度闪烁。

## D-010：默认首页延后

状态：已接受

参数化引擎、动态聚焦、性能和人工视觉选择完成前，不替换默认首页、不改造对话框和侧栏。

## D-011：引力织场只作为第一套技术骨架

状态：已接受

M1.2a 先实现 `gravitational-weave-tech-preview`，验证固定相机下由知识空间自身产生的拉伸、压缩、剪切、弯曲与恢复。技术审计通过不能把它自动升级为最终主视觉；动态视频人工验收仍是停止门。

## D-012：固定相机作为运动真实性基准

状态：已接受

M1.2a 的主要视觉验收使用固定相机，排除相机环绕、整景旋转和统一平移制造的伪流动。轻微协同漂移只作为补充视差，位移不得超过 `0.6` 世界单位，周期不得短于 60 秒。

## D-013：中央对话区采用缓流而非留空

状态：已接受

未来对话框区域使用固定世界空间缓流椭球，将位移和速度降低约 30%。它不清空中央星体、不形成明显圆洞，也不跟随相机实时移动。

## D-014：M1.2a 保持黑白且无后处理

状态：已接受

第一轮只用银白、冷灰和石墨灰验证运动骨架；语义星采用正常透明混合，不加入 Bloom、景深、运动模糊、拖影或时间透明度。颜色和相位呼吸只有在运动语言被人工接受后才进入下一阶段。
