# v0.22.0-beta.2 发布安全复核

## 范围

本报告覆盖受监督研究 Agent、schema 8/9/10/11 迁移、论文导入与清洗、V20 建模、报告导出、Windows Full/Lite 安装包。在线学术来源与校园图书馆连接器不在本版本中。

## 关键威胁与缓解

- **未经审批的业务写入**：导入、清洗、建模和正式导出均为 `high` 风险。计划批准不能替代动作批准；批准绑定工具版本、registry、解析后参数和资源指纹。
- **崩溃造成半提交**：SQLite 业务修改、库修订、快照状态、Artifact、步骤、事件和 receipt 共用一个短事务。V20 计算在事务外完成，活动快照只在最终事务中切换。
- **重复执行**：operationKey、动作哈希和不可变 receipt 提供幂等收敛；租约 owner、token 与 generation 阻止失去租约的执行器提交。
- **文件导出中断**：输出文件名绑定 operationKey，经 `.partial`、`fsync`、内容哈希和原子改名发布。文件已落盘但 receipt 未提交时，重试只接受相同哈希，不覆盖不同内容。
- **路径和资源替换**：资源授权绑定数据库实例、项目、运行、规范路径、大小、格式、SHA-256 和有效期。审批后资源变化会使动作失效。
- **凭据泄露**：AI Key 与 MySQL 密码只从 Windows Credential Manager 或明确允许的开发环境变量读取；WebView 只能获知是否已配置。计划、事件、Artifact、错误、备份和发布文件禁止保存凭据或完整模型响应。
- **模型提示注入**：论文标题、摘要与外部数据标记为 `untrusted_data`。模型不能修改工具风险、预算、审批策略或确定性完成门禁。
- **模型供应链**：语义模型固定到 multilingual-e5-small 的精确 revision；模型、Tokenizer 和配置逐文件校验大小与 SHA-256，并随安装包附带 MIT 许可。
- **危险输出**：HTML 导出转义报告文本，不启用原始 HTML、脚本、内联事件或危险协议。没有 SQL、Shell、任意 URL 或通用文件写入工具。
- **迁移破坏**：既有用户库升级前创建并验证同目录在线备份；迁移失败保留原数据库。高于 schema 12 的库拒绝写入。

## 发布门禁

发布要求事务故障注入、迁移、凭据扫描、100,000 篇压力测试、12 项真实模型质量评测、原生桌面流程和 Windows 安装/升级/卸载全部通过。任何凭据、快照混用、引用越界、未授权写入或高风险复核绕过均为发布阻断项。

## 残余风险

- 安装包未代码签名，Windows SmartScreen 可能警告；用户必须从 GitHub prerelease 获取并核对 SHA-256。
- AI 请求会把已批准的有界证据发送给用户配置的模型服务商；其数据保留政策由服务商决定。
- MySQL 导入依赖用户提供的只读账号与源库可用性；本应用无法替代源数据库侧权限治理。
- Windows、WebView2、显卡驱动和第三方模型服务的异常仍可能造成任务暂停，但不得绕过 receipt、租约或审批边界。
- 本版本不提供在线学术连接器，不能把本地证据覆盖度等同于全球文献完整度。

## 安装包说明

`v0.22.0-beta.2` 是未签名 Windows x64 prerelease。Full 包含 schema 12 的语义 V20 数据快照、CPU 与 DirectML 模型；Lite 创建 schema 12 空库并包含便携 CPU 模型。升级、重装和卸载不删除用户选择的外部数据库目录或 Credential Manager 凭据。
