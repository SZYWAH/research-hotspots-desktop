# 科研 Agent 项目目标

状态：权威事实入口

更新时间：2026-07-27

## 最终目标

将现有科研热点工作站发展为以本地论文证据为基础的科研 Agent。程序默认入口最终应是全屏沉浸式星空中的极简对话空间；论文库、热点库、报告、星图和建模能力作为可追溯工具由 Agent 或用户调用。

详细产品定义见 [科研 Agent 最终产品目标](./RESEARCH_AGENT_PRODUCT_GOAL.md)。

## 当前里程碑

M1“沉浸式视觉方向确认”的开发前准备已经完成，参数化星河引擎正式实现尚未开始。

旧 `voyage / breath / signal` 三套 Agent 背景原型已经证明轻量载荷、独立渲染器和评审入口可用，但未通过人工视觉验收。当前工作不是调参。可替换的参数化流动星河引擎已经具备开发基线、接口、测试实体和验收标准，下一阶段按这些冻结条件开始实现。

## 当前数据事实

- 固定背景来源：理论星图快照 `project-default:v20:1784975696989`。
- 来源论文：25,463 篇。
- 来源热点：160 个。
- 常驻背景论文代理：3,840 个，每热点最多 24 个。
- 生产理论布局：`semantic-hierarchical-natural-pca3-v3`。
- UMAP-A/B/C 继续隔离，不属于生产布局。

可审计数值与哈希见 [Agent 星河准备基线](./evidence/agent-galaxy-flow-baseline-2026-07-27.json)。

## 当前阶段范围

本阶段包含：

- 冻结旧背景原型基线。
- 定义参数化 `FlowModel`、焦点意图和实体解析契约。
- 锁定锐利星体、低饱和色彩、粒子预算和连续性要求。
- 准备真实论文、热点和边界测试夹具。
- 规划新的隔离参数实验室和审计替换路径。

本阶段不包含：

- 实现正式流场或选择最终流动形态。
- 替换默认首页、对话框或侧栏。
- 修改展示星图、理论星图、活动快照或 UMAP。
- 新增数据库表或迁移。
- 构建安装包、推送、PR、合并或发布。

## 本阶段成功标准

- 项目目标、路线、状态、架构和决策具有统一事实入口。
- 旧视觉候选被明确记录为 `FAIL`，基础设施能力与产品验收不再混淆。
- 流场、动态聚焦和实体解析接口不要求实现者临时补充产品决定。
- 测试夹具覆盖常驻论文、快照内未抽样论文、活动库新信号、热点、多实体和不存在实体。
- 视觉不变量和初始预算可以由准备阶段审计检查。
