# 科研 Agent 项目目标

状态：权威事实入口

更新时间：2026-07-28

## 最终目标

将现有科研热点工作站发展为以本地论文证据为基础的科研 Agent。程序默认入口最终应是全屏沉浸式星空中的极简对话空间；论文库、热点库、报告、星图和建模能力作为可追溯工具由 Agent 或用户调用。

详细产品定义见 [科研 Agent 最终产品目标](./RESEARCH_AGENT_PRODUCT_GOAL.md)。

## 当前里程碑

M1“沉浸式视觉方向确认”已经完成 M1.2a“引力织场黑白运动骨架”和 M1.3a/M1.3b-1 的常驻论文聚焦技术验证。现有恒星光球能够证明同一顶点、连续焦点场和共速相机可行，但“圆点放大缩小”的产品表达未被采用。

M1.3c“理论坐标 + 沉浸外壳”实验在 Tauri 实机中判定为结构性 `FAIL`。代码虽然完成了六态、上下文抽取和实体解析，但沉浸画布仍继承热点中心与论文语义偏移，因此启动后仍像理论星图，不能作为 `agent背景.html` 的产品迁移。

当前进入 M1.3d“真正的沉浸/理论双背景静置闭环”。沉浸背景改为会话随机、身份真实、空间不承载理论含义的 Curl 流星海；理论背景继续使用真实理论布局。两套背景先分别落地并人工通过，再设计各自的聚焦和 Agent 状态。

旧 `voyage / breath / signal` 三套 Agent 背景原型已经证明轻量载荷、独立渲染器和评审入口可用，但未通过人工视觉验收。默认首页仍保持不变。

## 双背景目标

- 沉浸视图：用于 Agent 对话和沉浸体验。每次应用启动创建新的会话随机星海；真实论文/热点只提供身份和低饱和颜色，不提供理论位置。
- 理论视图：用于查看论文语义位置、热点归属和可解释关系，继续使用现有理论星图。
- 两种视图共享真实论文/热点身份和快照身份，但空间结构完全独立；禁止把沉浸位置解释为语义距离。
- 本版仅建立静置背景与显式切换，不实现聚焦、Thinking、六态动画或正式 Agent 后端。

详细准备边界见 [Agent 沉浸版背景保留式改造准备](./AGENT_IMMERSIVE_BACKGROUND_PREPARATION.md)。

## 当前数据事实

- 来源论文：25,463 篇。
- 来源热点：160 个。
- 常驻背景论文代理：3,840 个，每热点最多 24 个。
- M1.3d 沉浸会话目标：最多 6,000 篇唯一真实论文和全部 160 个真实热点；位置由会话种子生成，不读取理论 XYZ。
- 生产理论布局：`semantic-hierarchical-natural-pca3-v3`。
- UMAP-A/B/C 继续隔离，不属于生产布局。

可审计数值与哈希见 [Agent 星河准备基线](./evidence/agent-galaxy-flow-baseline-2026-07-27.json)。

## 当前阶段范围

本阶段包含：

- 冻结外部原型哈希、当前脏工作树和设备风险证据。
- 保留已接受的引力织场、载荷、实体顺序和同顶点聚焦能力。
- 建立沉浸视图与理论视图的共享身份和独立空间边界。
- 明确保留中央对话框、左右上下文构图、纯黑背景和 `Idle / Thinking / Focus` 三态。
- 将随机论文、随机位置、半径邻域、强塌缩和时间亮度闪烁列为必须替换项。
- 实现独立 `agent-immersive` 入口、沉浸工作区、真实上下文解析和左右证据面板。
- 支持六种 Agent 状态、常驻论文、快照未抽样论文、活动库外围信号、热点和不存在实体。
- 建立只读批量实体解析、24 槽动态语义层和沉浸/理论视图身份衔接。
- 后续按真实浏览器体验逐步调整构图、运动和材质，不再为每个视觉切片单独证明可行性。

本阶段不包含：

- 替换默认首页、正式对话框或侧栏。
- 接入正式 Agent 对话后端和生产首页调用链。
- 将隔离评审入口替换为默认 Agent 首页。
- 修改展示星图、理论星图、活动快照或 UMAP。
- 新增数据库表或迁移。
- 构建安装包、提交、推送、PR、合并或发布。

## 本阶段成功标准

- 外部原型、当前代码和设备状态拥有可复核基线。
- 双背景用途、共享身份和独立空间解释器边界明确。
- 原型保留项、小幅调整项和必须替换的随机逻辑不再混淆。
- 第一轮隔离评审入口已实现，并通过构建、类型检查、Rust 检查和数据/源码审计。
- 默认首页、活动数据库、展示/理论星图、活动快照和 UMAP 保持不变。
- 实现状态可记为 `PASS`；浏览器、Tauri 和用户视觉状态仍为 `UNVERIFIED`，不得提前标记阶段完成。
