# 后续开发路线

本文记录 `v0.22.0-beta.2` 理论星图生产修复之后的独立开发方向。以下内容均不属于当前
`v20-semantic-e5-small-3` / `semantic-hierarchical-natural-pca3-v3` 生产实现，不得在页面导航、
数据库迁移或热点建模过程中被自动启用。

## A. 完整语义重聚类实验

- 使用独立算法标识，例如 `v21-semantic-cluster-experimental-1`。
- 让 Embedding 同时参与热点边界、论文归属与热点位置计算。
- 对比约束 K-Means、HDBSCAN、kNN + Leiden 和两阶段聚类。
- 允许热点数量、名称、代表论文和成员随数据变化。
- 使用 schema 13 热点血缘记录拆分、合并与重命名关系。
- 在 25K 与 100K 数据上评估稳定性、语义纯度、可解释性、耗时和内存。
- 实验快照不得自动成为生产活动快照，必须经过人工 A/B 审查。

## B. 多学术来源与校园图书馆接入

- 支持公共学术 API、用户文件、用户数据库以及机构授权连接器。
- 优先使用机构 API、OAI-PMH、Z39.50 或供应商正式接口。
- 凭据保存到 Windows Credential Manager，并按项目和服务商隔离。
- 记录来源授权、许可、访问频率、provenance 和证据质量等级。
- 统一 DOI、标题、作者和内容级去重。
- 后续能力注册为受治理 Agent 工具；禁止任意 URL、Cookie 导出和绕过访问控制。

## C. 建模可视化与增量更新

- 建立“星系诞生观测站”，展示真实阶段、吞吐、缓存命中、剩余时间和提交状态。
- 只显示已经计算或已经提交的数据，不用预设动画伪造建模进度。
- 新增或修改论文优先复用旧 Embedding，只计算内容哈希变化的记录。
- 研究热点中心增量更新与触发完整重建的漂移阈值。
- 导入或清洗完成后只提示需要建模，继续禁止自动聚类。

## D. Deep Space Archive 界面

- Agent-first 简约首页和沉浸式深空背景。
- 默认折叠功能侧栏，首次启动只保留低干扰入口。
- 报告、热点、星图和文献工作台继续使用完整专业页面，不压缩必要信息。
- 不提供高对比主题。

## 启动顺序

当前生产星图修复和原生桌面验收完成后，再为上述方向分别建立计划和独立分支。优先顺序为：

1. 多学术来源与校园图书馆接入的合法数据边界设计。
2. 建模可视化与增量更新。
3. Deep Space Archive 界面。
4. 完整语义重聚类实验。
