# 科研 Agent 当前状态

更新时间：2026-07-27

当前分支：`codex/agent-galaxy-flow-engine`

来源基线：`33d97d45a952d489de4d08e941d14277d2c71f08`

当前阶段：M1.1 开发前准备已完成；M1.2 参数化星河引擎尚未开始

## PASS

- 理论星图和展示星图已有稳定基线，生产布局继续使用 v3。
- 轻量 `AgentGalaxyBackgroundPayloadV1` 已生成并通过确定性、身份、大小和哈希审计。
- 当前载荷包含 160 个热点和 3,840 个论文代理，文件小于 1 MiB。
- 独立 Three.js 背景渲染器、开发评审入口、质量等级、页面隐藏暂停、减少动态和性能快照已存在。
- 默认应用入口尚未替换，旧背景原型与正式星图隔离。
- 标准项目文档入口、流场/焦点内部契约和旧审计替换清单已经冻结。
- 确定性夹具覆盖 2 篇常驻论文、2 篇快照内未抽样论文、1 个活动库新信号夹具、1 个缺失实体、6 个热点和 2 组多实体场景。
- `pnpm build`、背景载荷、旧基础设施、准备阶段、理论相机、热点过渡、星图视觉不变量、UMAP 隔离和版本一致性审计均通过。

## FAIL

- `voyage / breath / signal` 三套视觉候选未通过人工验收。
- 主要问题包括固定坐标感、整组旋转/缩放代替真实流动、热点过强、论文星不明显、色彩过于突出和整体模糊。
- 因视觉验收失败，M1 不能标记完成，即使旧自动审计仍能通过。

## UNVERIFIED

- 参数化 GPU 流场及可替换 FlowModel。
- 全分辨率锐利语义星与光晕/微尘分层。
- 快照内未抽样论文和活动库新信号的动态聚焦。
- 新参数实验室及新的动态录屏验收。
- 新方案在 Iris Xe、RTX 4060 和 Tauri 原生窗口中的最终性能。

## 当前风险

- 旧视觉审计仍绑定三个已否决 preset，必须在正式实现时被新审计替换。
- 当前背景 Canvas 同时承担数据、Shader、相机、状态和质量逻辑，直接继续叠加会扩大维护风险。
- 产品目标文档允许景深，但新决策明确禁止景深作用于语义星；旧表述需要以后按渲染层解释。
- 动态聚焦不能依赖 3,840 个常驻代理，必须有按 ID 解析的数据通路。

## 下一步

1. 开始 M1.2，将单体背景 Canvas 拆为流场、渲染层、相机、焦点和质量模块。
2. 先实现无颜色、无 Bloom 的技术流场验证，不预选最终主视觉。
3. 按冻结契约实现锐利语义星通道和连续粒子运动。
4. M1.2 完成前继续保持默认首页、正式 Agent 后端和数据库不变。
