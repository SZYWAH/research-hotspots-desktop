# 科研 Agent 项目目标

状态：权威事实入口

更新时间：2026-07-28

## 最终目标

将现有科研热点工作站发展为以本地论文证据为基础的科研 Agent。程序默认入口最终应是全屏沉浸式星空中的极简对话空间；论文库、热点库、报告、星图和建模能力作为可追溯工具由 Agent 或用户调用。

详细产品定义见 [科研 Agent 最终产品目标](./RESEARCH_AGENT_PRODUCT_GOAL.md)。

## 当前里程碑

M1“沉浸式视觉方向确认”已经进入 M1.2a“引力织场黑白运动骨架”的实现与验证。该骨架用于验证一种新的空间运动语言：在固定相机下，由知识空间自身产生连续的拉伸、压缩、弯曲与恢复。

`gravitational-weave-tech-preview` 只是参数化引擎的第一个技术骨架，不是最终产品主视觉。自动审计可以确认确定性、连续性、清晰度和隔离边界；视觉是否成立仍必须由 15–30 秒动态材料人工判断。

旧 `voyage / breath / signal` 三套 Agent 背景原型已经证明轻量载荷、独立渲染器和评审入口可用，但未通过人工视觉验收。当前工作不是继续调节旧候选。可替换的参数化流动星河引擎已经具备开发基线、接口、测试实体和验收标准，M1.2a 在独立评审入口中实现第一套黑白运动骨架。

## 当前阶段范围

本阶段包含：

- 保留已冻结的旧背景原型、载荷和测试夹具。
- 将流场契约升级为可描述真实能力的 v2，并接入 `gravitational-weave-tech-preview`。
- 实现由四个不可见场节点驱动的确定性解析运动。
- 分离锐利论文星、锐利热点核心、环境星和暗微尘，并以黑白低干扰视觉验证运动。
- 提供固定相机、固定时间、质量预算和参数化的隔离评审入口。
- 建立技术静态审计，并为分级浏览器动态验收准备指标。

本阶段不包含：

- 将引力织场技术骨架直接选为最终流动形态。
- 最终颜色、Bloom、动态论文聚焦、思考涌现、时间地层或 Agent 状态编排。
- 替换默认首页、对话框或侧栏。
- 修改展示星图、理论星图、活动快照或 UMAP。
- 新增数据库表或迁移。
- 构建安装包、推送、PR、合并或发布。

## 本阶段成功标准

- 旧视觉候选被明确记录为 `FAIL`，基础设施能力与产品验收不再混淆。
- 相同快照、实体和时间输入得到确定性的场节点、分配与坐标。
- 语义星保持全分辨率锐利亮核，不读取时间透明度，不使用 Bloom、景深或运动模糊。
- 固定相机下可以证明运动来自粒子局部形变，而不是整组旋转、缩放或统一平移。
- 默认首页、活动数据库、展示/理论星图、活动快照和 UMAP 保持不变。
- 技术审计通过后状态可记为 `PASS`；动态视频经人工观看前，视觉状态必须保持 `UNVERIFIED`。
